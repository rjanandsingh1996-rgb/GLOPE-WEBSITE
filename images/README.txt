GLOPE WEBSITE V19
==================
V19 keeps the English website visually and textually intact and adds a manually written English ↔ Hindi switch.

Language switch:
- Desktop: EN / हिंदी in the header
- Mobile: Language / भाषा inside the menu
- Choice is saved in the browser using localStorage.
- English is the default.
- Hindi is written as natural, brand-appropriate Hindi rather than machine-translated text.

All existing GLOPE images and the FSSAI logo are included.
